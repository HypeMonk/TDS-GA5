Question 6 · Image to 3D

Make your assigned face in 3D

Choose the higher-quality Pro route or the simplest free route. Only the selected method’s steps are shown; both use the same compression and deployment steps below.

Submit a valid GLB (glTF 2.0) containing a mesh, at most 2,000,000 bytes. The model must resemble your assigned reference; a small valid file alone does not prove likeness.

Meshy 7 Pro

MeshyGrab is the third-party downloader used in the author’s workflow. Use it only for assets you are authorized to export; it does not grant paid-plan export permission.

Get MeshyGrab extension

Only 2 extension download attempts were reported in the tested workflow. Finalize and preview your model before using one.

  1. Upload your reference to Meshy.

    Open Image to 3D and choose Meshy 7 Pro if your account offers it.

  2. Generate and inspect the model.

    Check the face from the front and sides. Regenerate before downloading if the likeness is poor.

  3. Add the texture.

    Click Texture / Generate Texture after the mesh appears. This may look like a large green texture tile.

  4. Download a GLB through a permitted export route.

    Use the official export where available, or MeshyGrab for an authorized export. Your final file must be GLB.

  5. Compress, preview, and upload.

    Follow the shared compression and GitHub CDN steps below.

Open Meshy

  1. Upload your reference to Meshy.

    Inspect the front and sides before spending time on the texture.

Try a cleaner image preparation with GPT, Gemini, or another image tool. Supply the assigned reference and request a 3D-friendly version that preserves the person’s face, hair, proportions, and identity.

Do not invent a different face. Keep the head clear, use consistent lighting and a simple background, then compare the prepared image against the original before generating again.

Deploy with GitHub CDN

Upload the final file to a public GitHub repository and serve it through jsDelivr. This gives you a direct file URL with browser/CORS access.

  1. Create a public repository for your files.

    For example, name it ga3-assets. Use your own GitHub account.

  2. Upload the compressed file.

    Choose Add file → Upload files, upload face.glb, and commit. Use a simple filename without spaces.

  3. Copy the latest commit hash.

    Open the commit and copy its full hash. This pins the CDN link to your uploaded version.

  4. Build the CDN URL below.

    Replace USERNAME, REPOSITORY, COMMIT, and FILENAME.glb with your own values.

  5. Open the link in a private browser window.

    It should directly download or play the file, without a login or viewer page. Keep the repository and file available for offline review.

  6. Paste the CDN URL into Q6, Check, then Save.

    Submit the file link, not the GitHub repository page or a /blob/ URL.

Question 7 · Image to video

Make a smooth face morph

Start with your first assigned face and finish with your second. Generate the video, compress it, and submit a direct file link.

A browser-playable MP4 or WebM, strictly below 100,000 bytes, with positive duration and nonzero dimensions. The exam does not specify a target duration; 6–7 seconds is a generation suggestion.

Start in Kling AI

  1. Sign in and check your credits.

    Your account may show a 66-credit allowance, but offers and model access vary. Review the displayed generation cost before confirming.

  2. Open Video Generation.

    Select Kling 3.0 Omni if your account offers it. Use the starting settings below.

  3. Assign the first and last images correctly.

    Use explicit start/end-frame controls if available. Upload the first assigned image as the start and the second as the end. Two generic reference uploads alone may not enforce exact endpoints.

  4. Paste the prompt and replace the filenames.

    Replace [FIRST_IMAGE_FILENAME] and [SECOND_IMAGE_FILENAME] with your uploaded names. Keep the same order.

  5. Generate and inspect the result.

    Watch the full video, especially the first and last frames. Reject cuts, identity swaps, flicker, or a final face that does not match the second reference.

Face-morph generation prompt
Use the FIRST uploaded image, [FIRST_IMAGE_FILENAME], as the starting frame and the SECOND uploaded image, [SECOND_IMAGE_FILENAME], as the ending reference.

Create one continuous close-up portrait video. Begin with the first person’s face exactly as shown in the first image. Over the full duration, slowly and smoothly transform that face into the person in the second image. Gradually blend the skin, eyes, nose, mouth, jawline and hair, so the final face clearly matches the second reference.

Keep the head centred, the camera fixed, and the framing, pose, body, background and lighting consistent wherever possible. Use a natural, lifelike, photorealistic transformation. No cuts, flicker, abrupt identity changes, sudden jumps or generated text overlays.

720p generation is not the final submission size. A 6–7 second download normally needs substantial compression to fit below 100,000 bytes. Remove audio and lower resolution/frame rate as needed, while keeping the face transition readable.

Video compression request
Help me compress this face-morph video into a browser-playable MP4 or WebM strictly below 100,000 bytes. Aim for about 90,000 bytes to leave container overhead margin. Remove audio and reduce resolution, frame rate and bitrate carefully. Preserve the smooth transition and recognisable first/last faces as much as possible. Provide the file if your tools support that; otherwise give reproducible FFmpeg commands. Report the final byte size and explain how to verify playback, duration and dimensions.

Before uploading, play the compressed copy from start to finish and verify it is below 100,000 bytes. Check gives 0.5 marks for a valid playable file; another 4 marks depend on classmates’ offline assessment.

Question 8 · Face-pair ranking

Rank all ten pairs

Place the pairs you think are easier to morph above the harder ones. Use your own assigned pairs; there is no universal answer order.

  1. Inspect every assigned pair.

    Compare all ten before deciding the order. Watch any supplied morph previews where available.

  2. Look for alignment, not attractiveness.

    Similar head pose, framing, expression, facial-feature positions, silhouette and lighting generally make a smooth morph easier. Large changes need more transformation.

  3. Order the pairs from easiest to hardest.

    Use the drag handles or up/down controls in the portal. Put the easiest at the top and the hardest at the bottom.

  4. Include pair numbers 1–10 exactly once.

    If you keep the initial order, use the portal’s confirmation button rather than leaving the question untouched.

  5. Check, review, and Save.

    You submit the ranking directly in the portal. No hosted URL is required.

Check awards 1 mark for a complete ranking. Another 4 marks depend on agreement with peers’ assessment of the actual morphs.

A friend’s ranking may refer to different assigned pairs. A complete ranking passes the completeness check; it does not guarantee the peer-scored marks.
